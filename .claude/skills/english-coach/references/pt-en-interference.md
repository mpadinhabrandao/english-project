# Portuguese → English interference patterns

The errors Portuguese speakers make in English *because of Portuguese*. Each pattern has an ID so the coach and the learner's `ERROR_BANK.md` point at the same thing. Use the ID when correcting and when logging (`S04`, `P01`, `F21`…).

How to use: when you correct, check whether the error matches a pattern here. If it does, name the ID and give the one-line Portuguese contrast — that's what makes the fix stick. If it doesn't match, correct it normally with a category tag but no ID (a new recurring one can be added to `ERROR_BANK.md` as `X01`, `X02`…).

Portuguese examples are European Portuguese; the English side is the same for Brazilian speakers.

## S — Sentence structure

| ID | Portuguese habit | Typical error → Correct | Why |
|---|---|---|---|
| S01 | Subject dropped (*Está a chover.* *Tem um problema.*) | Is raining → **It's** raining · Have a problem here → **There's** a problem here | English always needs a subject: *it* for weather/time/general facts, *there is/are* for existence (*tem/há*). |
| S02 | Verb before subject (*Já existe algum projeto?* *Não sei onde está ele.*) | search if already exists some project → check whether a project **already exists** · I don't know where is he → I don't know where **he is** | Statements and embedded questions: Subject → Verb, always. |
| S03 | Questions by intonation only (*Onde moras?*) | Where you live? → Where **do** you live? · You like it? → **Do** you like it? | Questions need *do/does/did* (or another auxiliary) before the subject. |
| S04 | *Qual é…* → which | Which the best way? → **What's** the best way? | *Which* only for a small known set ("which of these two"); open questions use *what*. Don't drop *is*. |
| S05 | *Gosto muito de X* | I like very much football → I **really** like football / I like football **very much** | Nothing goes between the verb and its object. |
| S06 | *Quero que faças* | I want that you do it → I want **you to do** it | want / need / ask / tell + person + *to*-infinitive. |
| S07 | *Antes de começar* (infinitive) | Before start, I think… → **Before starting** / **Before we start**, I think… | After *before / after / without / instead of*: -ing or a full clause. |
| S08 | Infinitive without *to*, or *to* after modals | I prefer star → I prefer **to start** · I can to do → I **can do** · Let's to go → **Let's go** | prefer / want / need / decide / plan + *to*; modals and *let's* never take *to*. |
| S09 | *Estou de acordo* | I am agree → I **agree** | *Agree* is a verb, not an adjective. |

## N — Articles & number

| ID | Portuguese habit | Typical error → Correct | Why |
|---|---|---|---|
| N01 | No article with professions (*Sou programador*) | I am developer → I am **a** developer | Singular countable nouns need *a/an* (or *the*, *my*…). |
| N02 | *O/a* with generalities (*As pessoas…*, *Gosto da música*) | The people like… → **People** like… · I like the music → I like **music** | No *the* for things in general; *the* only for a specific one. |
| N03 | *Uns/umas* → "a" before a plural | create a skills → create **skills** | *a/an* is singular only. |
| N04 | Countable in PT, uncountable in EN | informations → **information** · advices → **advice** · feedbacks → **feedback** · softwares → **software** · a planning → **a plan** · a travel → **a trip** · a work → **a job** · a news → **some news** | No plural, no *a/an*; use *some / a piece of / a bit of*. |
| N05 | Adjectives agree (*diferentes opções*) | differents options → **different** options | English adjectives never change form. |
| N06 | *A gente é / as pessoas são / todos são* | people is → people **are** · everybody are → everybody **is** | *People* is plural; *everybody / everyone / nobody* are singular. |

## V — Verbs & tenses

| ID | Portuguese habit | Typical error → Correct | Why |
|---|---|---|---|
| V01 | Present simple for "right now / these days" (*Faço dois cursos*) | Currently I do two courses → I'**m** currently **doing** two courses | Temporary or in-progress activities → present continuous. |
| V02 | *Há três anos que moro aqui* | I live here since 3 years → I'**ve lived** here **for** 3 years / **since** 2023 | Unfinished period → present perfect; *for* + duration, *since* + start point. |
| V03 | *Pretérito perfeito* covers everything | Yesterday I have finished → Yesterday I **finished** · they make something better (last year) → they **made** something better | Finished time → past simple, and the verb must actually be marked for past. Result-now → present perfect. |
| V04 | *Ter* for states (*tenho 30 anos, tenho fome, tenho razão*) | I have 30 years → I'**m** 30 · I have hunger → I'm **hungry** · You have reason → You'**re right** | Age, hunger, thirst, cold, fear, being right → *be* + adjective. |
| V05 | *Nasci em* | I born in Porto → I **was born** in Porto | Always passive: *was/were born*. |
| V06 | *Fazer / dar* collocations | make a course → **take / do** a course · make questions → **ask** questions · do a mistake → **make** a mistake · make a party → **have / throw** a party · make exercise → **do** exercise / **work out** | Learn the English verb *with* the noun; *fazer* has no single translation. |
| V07 | *Ficar* (stay / become / be located / get) | I stayed tired → I **got** tired · The office stays in Lisbon → The office **is** in Lisbon · Fica para amanhã → **Leave it** for tomorrow | Pick the meaning first, then the verb: stay (remain), get/become (change), be (location). |
| V08 | *Dizer* for both | He said me that… → He **told** me that… / He **said** that… | *tell* + person; *say* + thing (or *say to* + person). |
| V09 | *Conhecer* = meet or know | I knew him last year → I **met** him last year | First encounter → *meet*; ongoing acquaintance → *know*. |
| V10 | *Perder* = lose or miss | I lost the bus / the meeting → I **missed** the bus / the meeting | Transport, events, chances → *miss*; objects → *lose*. |
| V11 | *Passar tempo* | We passed a good time → We **had** a good time · pass time with friends → **spend** time with friends | |
| V12 | *Ter uma dúvida* | I have a doubt → I have **a question** | *Doubt* = suspicion something is false; asking for information = *question*. |

## P — Prepositions

| ID | Portuguese habit | Typical error → Correct | Why |
|---|---|---|---|
| P01 | *depender de* | depends of → depends **on** | |
| P02 | *pensar em* | think in → think **about / of** | |
| P03 | *chegar a* | arrive to Lisbon → arrive **in** Lisbon · arrive to the office → arrive **at** the office | *in* for cities/countries, *at* for buildings/points; *home* takes no preposition. |
| P04 | *casado com / casar com* | married with → married **to** · I married with her → I **married** her | |
| P05 | *sonhar com* | dream with → dream **about / of** | |
| P06 | *ouvir* (no preposition) | listen music → listen **to** music | |
| P07 | *explicar-me* | explain me → explain **to** me / explain it **to** me | Also: *say to me*, *suggest to me*, *describe it to me*. |
| P08 | PT needs a preposition, EN doesn't | answer to the question → **answer** the question · enter in the room → **enter** the room · call to him → **call** him · ask to him → **ask** him · need of → **need** · like of → **like** | |
| P09 | *discordar de / consistir em* | disagree of → disagree **with** · consist in → consist **of** | |
| P10 | Time expressions (*em segunda, à noite, na semana passada*) | in Monday → **on** Monday · in the night → **at** night · in the morning of Monday → **on Monday morning** · in the last week → **last week** · in this moment → **right now / at the moment** | *last / next / this / every* + time word takes no preposition. |
| P11 | *para* (purpose) → to | a tool to this purpose → a tool **for** this purpose · I'm here **to** help ✓ | *for* + noun, *to* + verb. |

## T — Typing & spelling (fast to fix, high impact)

| ID | Habit | Typical error → Correct | Fix |
|---|---|---|---|
| T01 | *de* → the | de same ideas → **the** same ideas | Keyboard autocorrect from a PT keyboard. Switch the keyboard language when writing English, or add "the" to the dictionary. |
| T02 | *i* → I | i prefer → **I** prefer | Always a capital. |
| T03 | Dropped last letter | star → start · tha → that | One re-read before sending. |
| T04 | Double letters in cognates | comunication → communication · adress → address · profesional → professional | Cognates are the trap: PT has one letter, EN two. |

## What Portuguese speakers usually get right (don't over-correct)

- Romance cognates give a huge formal vocabulary for free (*investigate, propose, currently, improve, documentation*). The gap is *informal* English: phrasal verbs (*find out, set up, deal with, end up, figure out*) and short verbs (*get, take, put*). Teach those.
- Long, formal sentences are fine in writing but sound stiff when spoken. For speaking, teach short chunks and contractions.
